Where LOCI sits on the AI stack

The usual stack chart shows GPUs, models and simulators. LOCI covers the compiled C, C++, Rust and Go code on the Arm CPU next to them: the control ticks, parsers and pre- and post-processing that decide whether a robot or camera meets its deadline.

LOCI's span: the CPU code between the simulator and the shipped device

Before the gateThe simulator runs on simulated time, so a slow control tick still looks on time.
At the gateLOCI times the compiled function on the target core model and judges it against the accepted contract.
After the gateOnly code that meets its worst-path, stack and energy bounds reaches Jetson.
